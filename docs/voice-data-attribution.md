# Voice location data attribution

UK city and town vocabulary is derived from the SimpleMaps United Kingdom Cities Basic database and is used under the Creative Commons Attribution 4.0 licence.

Source: https://simplemaps.com/data/uk-cities

The generated application database records this attribution in `voice_metadata`. The current checked-in source is a reduced 5,592-term export retained from the previously downloaded Basic dataset. Geographic columns in the schema are nullable so a complete licensed release can be regenerated without an application migration.
